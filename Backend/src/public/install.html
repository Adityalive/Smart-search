Install the Chrome Extension

Smart-search is distributed via GitHub Releases — completely free, no Chrome Web Store needed. Follow these 6 simple steps to get the extension running on your browser in under 2 minutes.

↗ GitHub Repository

🐙
Open Source · GitHub
github.com/Adityalive/Smart-search
→
⚠️ You will need Google Chrome (or any Chromium browser like Brave, Edge, Arc) to use this extension.

1 Download the Extension ZIP

📦
Go to the Releases page
On the GitHub repo page, look for the Releases section in the right sidebar, or click the link below directly.
🚀
Latest Release
github.com/Adityalive/Smart-search/releases
→
⬇️
Download the ZIP file
Under the latest release, find the Assets section and click the file ending in .zip. It will download to your computer automatically.

2 Unzip the Downloaded File

🗂️
Extract the folder
Find the downloaded .zip file (usually in your Downloads folder). Right-click it and select:
# Windows
Right-click → "Extract All..." → Choose a location → Extract

# Mac
Double-click the .zip — it extracts automatically
⚠️ Remember where you extracted the folder. Chrome needs to access that folder permanently — do not delete it.

3 Open Chrome Extensions Page

🌐
Navigate to the Extensions page
Open Google Chrome and type the following URL in the address bar and press Enter:
chrome://extensions

4 Enable Developer Mode

🔧
Toggle Developer Mode ON
On the Extensions page, look at the top-right corner. You'll see a toggle labeled "Developer mode". Click it to turn it ON.
✅ When enabled, you'll see three new buttons appear at the top: "Load unpacked", "Pack extension", and "Update".

5 Load the Extension

📂
Click "Load unpacked"
Click the "Load unpacked" button that appeared after enabling Developer Mode. A file picker dialog will open.
🎯
Select the extracted extension folder
Navigate to where you extracted the ZIP file in Step 2. Select the extension folder (the folder that contains manifest.json) and click Select Folder.
✅ The Smart-search extension will now appear in your Chrome extensions list with its icon in the toolbar!

6 Login & Start Using

🔑
Create an account or login
Click the Smart-search icon in your Chrome toolbar (top-right). Register a new account or sign in with your existing credentials.
⚡
Save pages instantly
While browsing any webpage, click the extension icon and hit Save. The page will be automatically scraped, tagged with AI, and added to your personal knowledge base.
🔍
Search your saved content
Visit the Smart-search web app to semantically search everything you've saved — even if you can't remember the exact title or URL.
🎉 You're all set! Your browser is now your personal AI-powered knowledge base.

? Troubleshooting

Common Issues
❌ Extension doesn't appear after loading
Make sure you selected the folder that directly contains manifest.json, not a parent folder.
❌ Icon missing from toolbar
Click the puzzle 🧩 icon next to the address bar and pin Smart-search to your toolbar.
❌ Can't login or save pages
Make sure you've registered an account on the Smart-search web app first.
